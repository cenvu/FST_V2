## Capture-fixture notes

- Each state uses an isolated temporary source/destination pair; no owner media
  is selected and no copy, verification, Telegram message, or report is run.
- Copy/verify values reuse the approved Patch 1 native capture fixture values.
- The error message `TRANSFER ERROR: rsync failed.` is an existing wording
  fixture in `FishSockTransfer/Tests/ReportEngineWordingTests.swift`; the error
  capture carries no runtime snapshot, progress, ETA, speed, or file counts.
- The harness uses the repository’s bundled rsync 3.4.4 only for its `--version`
  availability probe so READY is a true startable ready state. It does not
  invoke a transfer.
